# 커스텀 라이트매퍼 기획서 (v14)

> Unity 2021.3.45f1 · Built-In RP · C# / HLSL · Progressive Lightmapper 대체
> **v14: 인스턴싱 SH 트랙 SH-1~5 엔드투엔드 완결 + 검증 자동화.** 어댑터 `TemplateInstanceSource`(Mesh 템플릿 + per-instance Matrix4x4[][] → 코어 씬·대표점, 코어 무수정, `AnchorMode` 4종 프로브 배치). 정적 대량(DrawMeshInstancedIndirect) **하이브리드**: 대형 메시(건물)=텍스처 라이트맵(AtlasApplyDebug), 소형 메시(프롭)=**per-instance SH9 + StructuredBuffer**. SH 경로: SH-1 `SH9`, SH-2 `BurstSHBaker`(1바운스+앰비언트), SH-3 `SHPacked`/GraphicsBuffer, SH-4 뷰/데모, SH-5 셰이더(`EvaluateSH9.hlsl` 공유 + URP 2-프로브) — **실 드로우(`SHRenderDemo`) 동작·아티팩트 4종 수정·GPU 디코드 자동 검증(`SHEvalProbeGpuTests`, RunAll 배선)까지 완료.** 실 템플릿 FBX(Adonis_Snackbar A/B) 씬 반입. 잔여: BIRP 포팅·임의 회전 프로브 축·다바운스·인스턴스 오프셋 인덱싱 검증.
> 기반: G0~G3(Burst) + 후처리(step 8) 전달, Burst 경로 CPU와 ε 동등(77만 텍셀 mean≈0). 상세는 끝 「변경 이력」·개발문서 §8·§12.

## 2. 아키텍처 — 2-트랙 + 단일 공유 코어

원칙: **"출력 표현 2개, 파이프라인 1개"**. 트레이서/가속구조를 트랙별로 분기 금지(1차 리스크).

- **공유 코어**: SceneCollector(+분류, 미구현), MeshCleaner(미구현), BVH(단일 + 2단 TLAS/BLAS, **구현·검증**), RadianceCore(`EvaluateRadiance`, AO/Direct/Indirect **구현·검증**), 광원/스카이(Directional + ISky, **구현**), Linear 색, 디노이저(미구현).
- **Track A(건물/프롭)**: 텍스처 라이트맵, UV 파이프라인 전체.
- **Track B(식생)**: Light Probe/SH9(주) + 정점 베이크(보조), 텍스처 회피.
- **단일 진입점** `EvaluateRadiance(point, normal)`.

## 3. 공유 계약

| 계약 | 상태 |
|------|------|
| 색 공간 | Linear 전 구간 (결정·적용) |

## 5. 핵심 설계 결정

### 5.1 파라미터화 (Track A)
- **평면투영 1차** — 구현. 평면 차트 무왜곡·foldover 없음.
- **LSCM 2차 / MVC 폴백** — **스텁**(둘 다 `LogWarning("미구현 stub")`; `ChartFlattener`가 Planar→LSCM→MVC 디스패처로 연결, 솔버 본체 미구현).
- **외부 언랩(xatlas) 미도입** — 자체 경로 유지(§9.1 ⑤).
- 식생: 프로브(주) + 정점(보조).

### 5.2 가속구조 (구현·검증 — §6)
- 단일레벨 BVH(NativeArray 평탄, Median/binned SAH 12bin) + 2단 TLAS/BLAS(메시당 BLAS 공유 + 인스턴스 TLAS).
- 2단 속성 조회: `IntersectInstanced`, `TransformNormalToWorld`(역전치 `(M⁻¹)ᵀ`, 비균등 스케일 정확).
- IOccluder로 BruteForce·단일·2단 교차검증.

### 5.3 per-instance ST (유효)
- 유니크 메시 1회 언랩(공유 uv2) + 인스턴스별 ST. `UNITY_INSTANCED_PROP` 배칭 유지.

### 5.4 라이팅 (구현·검증 — §6)
- `EvaluateRadiance = Direct(NEE) + Indirect(경로추적, RR)`. (레거시 오버로드 `Direct + ambient×AO`도 유지)
- 코사인 중요도 샘플 → 히트에서 π·1/π 상쇄(알베도만 누적), π는 하늘(미스) 항에만.
- 차폐 추상화(IOccluder) 유지. 알베도: 모드 A(per-mesh) / 모드 B(per-instance·submesh) 둘 다 구현.

### 5.5 기타
- 레이 바이어스(`RayBias`), Push-Pull dilation(미구현), Octree(설계), Half-Edge 임시 생성 후 폐기.

## 7. 인스턴싱 × 라이트맵
- 공유 uv2 + per-instance ST + Texture2DArray. 배칭 유지(`UNITY_INSTANCED_PROP`).
- 2단 GI 베이크: 메시 dedup → BLAS 공유, 월드 전개 없음(메모리 ∝ 메시 종류 수). `InstancedRadianceScene`.
- 최종 인코딩 RGBAHalf(8MB/1024² 페이지)는 step 8에서. 현재 디버그 아틀라스는 RGBA32.
- **MeshFilter-free 경로**: `TemplateInstanceSource`(구 `MatrixInstanceSource`)가 (Mesh 템플릿[] + per-instance Matrix4x4[][]) → 로컬 Tri[][]·`Instance{MeshIndex,L2W}`·메시 알베도·**인스턴스 대표점(M·anchor)**·시드 산출. 코어(TwoLevelBVH/InstancedRadianceScene) 무수정 재사용. `ToBurstScene`/`ToBakeArrays`로 Burst 베이크 직결. `surfaceLift>0`이면 대표점을 템플릿 윗면(+Y)+여유로 올려 솔리드 내부 자기차폐(갇힌 프로브→SH=0) 회피.
- **정적 대량(DrawMeshInstancedIndirect) 하이브리드**:
  - 대형 메시(건물 5~10종) → **텍스처 라이트맵**(AtlasApplyDebug, 벽면별 그림자/바운스 표현). 종류 적어 ST/아틀라스 부담 없음.
  - 소형 메시(프롭, ~수만) → **per-instance SH9**(대표점 1점, 방향 전구면 샘플). `StructuredBuffer<SH9>`(50k×9×float3≈5.4MB). InstanceID 인덱싱.
  - 차폐 씬(2단 BVH)엔 크기 무관 전부 포함 → 서로 그림자/바운스 반영.
  - 직사광은 SH 밖(셰이더 실시간, 링잉·그림자 뭉개짐 방지). SH엔 간접+환경만.
  - SH 경로는 어댑터+`BurstSHBaker`(신규 컴포넌트)로 분리. AtlasApplyDebug는 텍스처 전용 유지, 씬 구성·광원(`_sun`/`_sky`)·시드 규약·베이크 백엔드 패턴만 참조·재사용.
- xatlas류 "메시별 고유 uv2"는 인스턴싱과 충돌 → 미도입.

### 8.1 검증 스위트 (등록 테스트)
- `BVHTests` — 단일 Median/SAH 퍼즈 + 2단 TLAS/BLAS ≡ brute (miss=0/5000).
- `RadianceIndirectTests` — a) π·L b) 하늘0→0 c) 흑박스0 d) 에너지보존 e) RR 무편향.
- `InstancedSceneTester` — 2단 ClosestHit(위치·노멀·알베도) ≡ brute + Indirect inst≡brute.
- `InstancedSceneModeBTests` — 모드 B(인스턴스·submesh 알베도) 정확성.
- `AtlasApplyDebug.RadianceDiffTest` — 베이크 실레이로 BruteForce vs BVH 픽셀 차이.
- `NormalTransformTests` — **비균등 스케일** 노멀 역전치 자기완결 단언(정답∥기하노멀 + 비공허성: 순진한 M·n 어긋남). ← 기존 갭 닫음.
- `LightmapPostProcessTests` — dilation(거터 채우기) valid 보존·링 확장·경계 안전.
- `LightmapPostProcessCompare` — dilation Burst vs 직렬(_prev) 결과 일치 + 성능 비교.
- `BurstSceneTests`(G0) / `BurstRadianceCompareTests`(G2/G3) — Burst 경로 ≡ 관리형 TwoLevelBVH·RadianceCore(ε).
- `AtlasApplyDebug.RadianceGiBackendDiffTest` — 실제 GI 베이크에서 CPU vs Burst 백엔드 텍셀 차이(77만 텍셀 MATCH).
- `LightmapSeamStitchTests` — 시임 Tier1(정점: 그룹 평균·비그룹 보존·매핑/클램프).
- `SeamEdgeTests` — 시임 Tier2(모서리: 모서리쌍 유도·정규화·미러 + StitchEdges 평균·길이불일치 무누락).
- `TemplateInstanceSourceTests`(SH) — Mesh+Matrix 어댑터 ≡ MeshFilter 경로: 구조·대표점·5000레이 거동·알베도 폴백.
- `SH9BakeTextureTest`(SH-1) — SH9 프로젝션 항등식(균등 coeff0·mean(E)≈π·c / 선형성 / 그라디언트 방향성).
- `BurstSHBakerTests`(SH-2) — per-instance SH9(빈씬 E≈π·L / 그라디언트 방향성 / 바닥 hit 반사).
- `SHPackedTests`(SH-3) — SHPacked 7×float4 왕복·정렬·셰이더 디코드 순서.
- `SHEvalProbeGpuTests`(SH-5) — GPU 셰이더 디코드 자동 검증(EditMode): 방향 의존 컬러 SH 1개를 stride-112 `StructuredBuffer<SHPackedGPU>` 업로드 → `SHEvalProbe.shader`(`InstancedSH_*`와 동일한 `EvaluateSH9.hlsl`) 1×1 float RT Blit → ReadPixels → 노멀 10종에서 CPU `SH9.Evaluate`와 ε(2e-3) 대조. 패킹 순서·상수·클램프까지 GPU≡CPU. (수동 하니스 `SHEvalProbeVerify`도 유지.) **미커버**: 단일 프로브(`_ProbeSH[0]`)만 보므로 인스턴스 오프셋(`iid*7`) 인덱싱·stride 계열 버그는 미포착. 렌더 컨텍스트 필요(헤드리스 CI 불가).
- 위 SH 테스트 5종(`TemplateInstanceSourceTests`·`SH9BakeTextureTest`·`BurstSHBakerTests`·`SHPackedTests`·`SHEvalProbeGpuTests`) 모두 `LightmapEvaluateDebugger.RunAll`에 배선(한 버튼 회귀).
