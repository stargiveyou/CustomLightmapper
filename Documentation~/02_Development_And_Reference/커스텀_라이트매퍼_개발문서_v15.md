## 4. A3/A4 — 정규화·패킹·통합 / 텍셀·ST
- **ChartFlattener**(v15.14) — Planar → LSCM → MVC 디스패처. `FlattenSettings`(Serializable — `AtlasApplyDebug.flatten`) · 차트별 `FlattenStats`(단계별 L2 stretch·겹침·반복 수 → `ParamResult.Stats`).
  1) Planar: 겹침 없음 ∧ L2 stretch ≤ `PlanarStretchThreshold`(기본 1.005 ≈ 원통 75° 호)면 확정 — 평면 차트는 stretch 1 이라 기존과 비트 동일.
  2) LSCM: 겹침 없고 (Planar 가 겹쳤거나 stretch 가 더 작으면) 채택, 아니면 유효한 Planar 로 복귀(거친 높이장처럼 등각이 면적을 크게 왜곡하면 Planar 가 이김).
  3) Planar·LSCM 모두 겹치면 MVC, 그래도 겹치면 뒤집힘이 가장 적은 후보. `FlattenSettings.FoldoverOnly`(임계 ∞) = 구 디스패치(겹칠 때만 LSCM).
- **LSCMSolver**(v15.14, Lévy 2002) — 삼각형 로컬 등거리 좌표의 Cauchy–Riemann 잔차 Σ W_j·U_j 를 면적 정규화 최소제곱(삼각형당 실수부·허수부 2행). 외곽 루프 근사 지름 2점 고정((0,0)·(d,0)) → 정규방정식(SPD) Jacobi 전처리 CG(double). 초기값 = 평면투영 UV 의 상사변환, 퇴화 삼각형 건너뜀 + 초기값 쪽 약한 정칙화(λ = 1e-9 × 평균 대각). 전개 가능 곡면(원통)은 L2 = 1(등거리)까지 편다.
- **MVCFallback**(v15.14, Floater 2003) — 외곽 루프를 원(3D 호길이 비례)에 고정, 내부는 MVC 가중 w_ij = (tan(α/2)+tan(β/2))/|e| 의 볼록결합 → 원판 위상이면 전단사. 가중 비대칭 → Jacobi BiCGSTAB(붕괴 시 Gauss–Seidel). 구멍은 가상 중심 + 부채꼴로 메워 원판화(자유 경계로 두면 구멍이 ≈3.4배로 부풂 — 테스트로 고정). 루프 정점 중복·공유(핀치)·경계 없음이면 false.
- **SparseSolver**(v15.14) — CSR(`SparseMatrix.Builder`: 행별 삽입 순서 합산 → 정렬 알고리즘과 무관하게 결정적) · CG · BiCGSTAB · Gauss–Seidel. 솔버는 로그를 남기지 않음(헤드리스 실행 가능).
- **UVValidator.Stretch**(v15.14) — L2 stretch(Sander 2001), 면적 정규화(등거리·균일 스케일 = 1).
- **UVPacker** — `DensityNormalizer`(s=√(meshArea/uvArea)) + `ShelfPacker`(배치 후보 3종 — 그대로 / 차트별 최소 bbox 가로 / 세로 — 중 점유 최대, 2026-10-28).
- **UVAssembler** — `SeamTable`, `Assemble`(uv2=ch1), `ParameterizationPipeline.Run`→`ParamResult`.
- **TexelMapper** — uv2→`LumelMap{WorldPos,WorldNormal,Valid,Bounds}`.
- **LightmapAllocator** — `InstanceLM{Id,LightmapIndex,ScaleOffset}`, `Allocate`(변∝√worldArea·density), `WorldArea`.
- **AtlasApplyDebug + LightmapDebug.shader** — 텍스처 트랙 베이크 드라이버(할당·텍셀·라이팅·후처리·적용). 이름에 Debug 가 남아 있으나 베이커 본체(§5.3).

> ⑪ 광원 = 태양 `DirectionalLight` + `ISky` + **로컬 광원 `BakeLight[]`(v15.17)**. 로컬 광원 계약(`LightSampling`):
> · **Point/Spot** E = Color·I·cosθ·감쇠, 감쇠 = 1/max(d²,1e-4) × 범위 창 saturate(1−(d²/R²)²)²(R=0 이면 없음) × 스포트 saturate((cos−cosO)/(cosI−cosO))² — URP 실시간과 같은 식. 반경(Unity Baked Shadow Radius) > 0 이고 샘플 > 1 이면 빛 방향에 수직인 원판을 샘플링한 가시도 평균(반그림자).
> · **Rect/Disc** = 한쪽(Direction) 램버트 방출, 방출 휘도 = Color·I. E = 면적·평균(cosθ_수신·cosθ_광원/max(d²,1e-4)·가시도), 상한 π·휘도. 범위 창 없음.
> · 샘플 위치는 **결정적 저불일치 수열**(태양 원반과 같은 u1 층화 + 황금비 u2, 위상 = `SunConeRotation(seed)`) → RNG 미소비라 광원이 있어도 간접광 RNG 스트림 불변, 광원 0개면 기존 결과 비트 동일. 1차 직사 = Direct 플래그 광원·광원별 Samples / 바운스 NEE = 전 광원·중심 1발.
> · 그림자 레이 o = p + n·1e-3, 길이 = |q − o| − 1e-3(천장과 같은 평면의 면광원도 안 막힘). `FlagShadows` 끄면 차폐 무시.
> · **SH·프로브(L2, v15.18)** — `LightSampling.ProjectSH`: SH 는 입사 복사휘도를 투영하고 평가 때 코사인 컨볼루션(SH9 규약)이라, Point/Spot 은 방향 l 의 델타(세기 = 수직 조도 E⊥ = Color·I·감쇠) → `c += E⊥·Y(ω_i)/N`(반경이면 원판 샘플 방향), Rect/Disc 는 방출 휘도 × 샘플 입체각 dΩ = (A/N)·cosθ_광원/max(d²,1e-4) → `c += L·Y(ω_i)·dΩ`(기하 입체각 합 상한 2π). 평가 E(n) ≈ 텍스처 경로 조도(L2 대역 근사 — 넓은 면광원 9% 이내). 그림자 레이 원점 = 프로브 점. 위상 = `SunConeRotation(프로브 인덱스 + 1)`. `AddDirectSH` = Direct 플래그 광원만(태양은 셰이더 실시간이라 SH 밖 — 기존 규약 유지).
> `EvaluateRadiance = Direct(NEE) + Indirect(경로추적·RR)`. 코사인 샘플로 히트에서 π 상쇄, 하늘 항에만 π. RR 생존확률 `clamp(max(tp),0.05,1)`, 생존 시 `tp/=pSurv`.

### 5.3 텍스처 GI 베이크 드라이버 — `AtlasApplyDebug`
- 모드: `PerInstanceColor/WorldNormal/Checker`(매핑 검증) · `Radiance`(직접+ambient×AO, `OccluderKind{BruteForce,BVH}`) · `RadianceGI`(직접+경로추적 Indirect).
- `RadianceGI`: `BuildGiScene`(메시 dedup → 유니크 로컬 + `ReadAlbedo` per-mesh Linear + 인스턴스) → `InstancedRadianceScene`(모드 A) → 백엔드 `RadianceBackend{CPU,Burst,Gpu}`(Gpu 불가 시 Burst 자동 폴백).
- **occluder-only**(v14.11): `occluders` 배열은 차폐 씬(`ResolveOccluderUnion`)에만 참여, 할당·베이크·머티리얼 스왑 제외.
- **배치 베이크(v15.15, G6-3b)**: 인스턴스 준비(파라미터화·텍셀 복원)를 `bakeBatchLumels`(기본 1<<20 valid lumel)까지 모은 뒤 1패스 조도 → SSAA 2패스(서브샘플 최대 4M 점씩) → 인스턴스 순서대로 blit·시임·메시 적용(`PendingBake` → `Flush` → `FinishInstance`). 백엔드 무관(GPU = 1 업로드·분할 디스패치·1 readback, Burst = 1 잡, CPU 루프). 텍셀 조도는 점·노멀·시드(인스턴스 안 li 기준)만의 함수라 배치 크기와 무관하게 **비트 동일**. `bakeBatchLumels = 0` = 인스턴스마다(구 거동). 에디터 진행 표시(배치 단위), 완료 로그 `batch=K×(≤N lumels)`. `LastBakeBackend`(internal)로 실제 백엔드 기록.
- **실행 단계(v15.16)**: `BakeAndApply` = `BeginRun`(할당·페이지 버퍼·가이드·씬) → `PrepareInstance`(파라미터화·텍셀 복원) → `FlushBatch`(배치 조도 + SSAA) → `FinishInstance`(= `BlitInstance` + `RegisterInstance`: 시임 입력·메시 적용) → `Compose`(denoise → 스티칭·dilation(CPU 또는 GPU) → 아틀라스) → `EndRun`(기록·로그·해제·저장). 상태는 `BakeRun` 한 객체 — 진행형이 같은 단계를 재사용(`ResetCanvas` + `BlitInstance` + `Compose` 로 미리보기 재합성). 구 단일 함수의 연산 순서 그대로.
- **적응 샘플링(v15.16)**: `adaptiveSampling`(기본 off) — RadianceGI 의 1패스·SSAA 서브샘플 조도를 `ProgressiveAccumulator` 로: 패스(`samplesPerPass`, 기본 32 spp — 2026-10-28 8 → 32, 패스 오버헤드)마다 같은 RNG 스트림을 이어 누적하고, `adaptiveMinSamples`(16) 이후 매 패스 끝에 텍셀별 표준오차 ≤ `adaptiveThreshold`(0.03) × (직사+간접) 휘도면 그 텍셀은 멈춤(`indirectSamples` = 상한). 경로가 전부 0 인 텍셀(분산 0 → 바로 '수렴')은 `adaptiveMinSamples` × 4 까지 유지 — 접촉 그림자가 0 으로 굳는 것 방지(2026-10-28). 판정은 관리 코드(double)라 백엔드·배치·진행형 여부와 무관하게 같은 텍셀이 같은 패스에 멈춘다. 끄면 구 경로(`BakePoints`) 그대로. 완료 로그 `adaptive(spp 평균 X/N, 경로 Y%, pass×K)`.

## 11. GPU/Burst 로드맵 (결정 ⑩ 실행)

핵심 병목 = **텍셀별 경로추적**(수백만 텍셀 × spp × 바운스 × BVH 순회). UV·패킹은 일회성 → 대상 아님.
순서: **Burst(저위험·NativeArray 재사용) → GPU(대규모)**. 각 단계는 기존 CPU를 ground truth로 ε-교차검증.

### 11.0 설계 원칙
- **POD 평탄화**: Burst/GPU는 `IOccluder`/`ISky`/`IRadianceScene` 가상 디스패치 불가 → 씬을 blittable NativeArray(SoA)로. BLAS/TLAS 노드·tri·인스턴스(L2W·노멀행렬·blasOffset)·알베도 테이블.
- **인터페이스는 ground truth 보존**: CPU 경로 정답 기준 유지, Burst/GPU는 별도 POD 경로. 백엔드 enum(CPU/Burst/Gpu) 선택.
- **결정성·교차검증**: 텍셀 시드(`seed + li*2654435761u`) 유지, ε 허용오차(fast-math off). RayAABB/RayTri/Rng/CosineHemisphere 를 재사용·비트 미러하면 사실상 정확일치.
- **GPU 행렬**: `Matrix4x4.GetRow(0..2)` 3행 업로드 → 셰이더가 `dot(row.xyz,v)+row.w` 로 명시 재현(column-major 트랩 회피).

### 13.2 Unity 2021.3 동작
- **언어/패키지**: C# 9(`using var`·readonly member·`Span<T> stackalloc`) 모두 2021.3 지원. Burst/Collections/Mathematics 2021.3 호환 버전 존재.
- **수정한 비호환 API**: `GameObject.FindObjectsByType<Light>()`(2022.2+ 전용) → `FindObjectsOfType<Light>()`(2021.3~Unity6 공통, U6 에선 deprecated 경고만). 1곳(AtlasApplyDebug).
