## 2. 아키텍처 — 2-트랙 + 단일 공유 코어

원칙: **"출력 표현 2개, 파이프라인 1개"**. 트레이서/가속구조를 트랙별로 분기 금지(1차 리스크).

- **공유 코어**: BVH(단일 + 2단 TLAS/BLAS) · RadianceCore(`EvaluateRadiance`, AO/Direct/Indirect) · 광원/스카이(Directional + ISky) · Linear 색 — **CPU(정답) / Burst(G0~G3) / GPU compute(G4~G6)** 3백엔드, 각각 교차검증. 미구현: SceneCollector(분류), MeshCleaner, 디노이저.
- **Track A(건물/프롭, 텍스처)**: UV 파이프라인 → 텍셀 → per-instance ST 아틀라스 → 후처리.
- **인스턴싱 SH 트랙(소형 프롭 대량)**: 인스턴스 대표점 SH9 + StructuredBuffer — 같은 코어(2단 BVH·경로추적)로 베이크.
- **Track B(식생)**: Light Probe/SH9(주) + 정점 베이크(보조), 텍스처 회피 — 공간 프로브 격자(`ProbeGrid`, 베이크는 SH 베이커 재사용) + 유효성·dilation(`BurstProbeValidity`)(v15.7) + 실사용 `ProbeVolumeBaker`·저장 `ProbeVolumeAsset`·인스턴스 대표점 샘플 적용(v15.8) + 픽셀 단위 볼륨 샘플 식생 셰이더(v15.9, 알파 클립·양면·잎 투과) + 템플릿 로컬 정점 AO(v15.10, uv3 앞/뒷면) + 알파 잎 차폐(v15.13, 컷아웃 머티리얼 구멍으로 베이크 레이 통과).
- **단일 진입점** `EvaluateRadiance(point, normal)` (Burst `BurstRadianceBaker` · GPU `CSRadiance` 가 미러).
- **베이크 코어 ↔ 테스트 분리**(v14.13): 코어 어셈블리 `HuskyLibs.CustomLightmapper` 는 테스트를 모름. 테스트·디버거·데모는 `HuskyLibs.CustomLightmapper.Tests`(에디터 전용 제약 → 빌드 제외).

## 5. 핵심 설계 결정

### 5.1 파라미터화 (Track A)
- **평면투영 1차** — 구현. 평면 차트 무왜곡·foldover 없음.
- **LSCM 2차 / MVC 폴백** — **구현(v15.14)**. 평면투영이 겹치거나 L2 stretch > 1.005(≈ 원통 75° 호)면 LSCM(2점 고정 + CG)을 풀어 왜곡이 작은 쪽, 둘 다 겹치면 MVC(원 경계 + 양수 가중, 구멍은 가상 부채꼴).
- **외부 언랩(xatlas) 미도입** — 자체 경로 유지(§9.1 ⑤).

### 5.2 가속구조
- 단일레벨 BVH(NativeArray 평탄, Median/binned SAH 12bin) + 2단 TLAS/BLAS(메시당 BLAS 공유 + 인스턴스 TLAS).
- 2단 속성 조회: `IntersectInstanced`, `TransformNormalToWorld`(역전치 `(M⁻¹)ᵀ`, 비균등 스케일 정확).
- IOccluder로 BruteForce·단일·2단 교차검증. Burst(`BurstScene`/`BurstTwoLevelBVH`)·GPU(`GpuScene`/`BvhTraverse.compute`)는 같은 레이아웃을 POD로 평탄화해 미러.

### 5.3 per-instance ST
- 유니크 메시 1회 언랩(공유 uv2) + 인스턴스별 ST. `UNITY_INSTANCED_PROP` 배칭 유지.

### 5.4 라이팅
- `EvaluateRadiance = Direct(NEE) + Indirect(경로추적, RR)`. (레거시 `Direct + ambient×AO` 오버로드 유지)
- 코사인 중요도 샘플 → 히트에서 π·1/π 상쇄(알베도만 누적), π는 하늘(미스) 항에만.
- 알베도: 모드 A(per-mesh) / 모드 B(per-instance·submesh) 구현. 실 베이크는 모드 A.
- **SH 다바운스**(v14.14): 같은 경로추적 루프를 프로브 방향별로 1경로씩 → SH 평가가 같은 점의 텍셀 간접 조도와 일치.

### 5.5 기타
- 레이 바이어스(`RayBias`), Push-Pull dilation(링 단위 dilation 으로 구현), Octree(설계만), Half-Edge 임시 생성 후 폐기.
- GPU 순회 스택 `BVH_STACK=32`(CPU/Burst 는 64) — 초대형 불균형 메시에서만 차이(§10).

## 7. 인스턴싱 × 라이트맵
- 공유 uv2 + per-instance ST + Texture2DArray. 배칭 유지(`UNITY_INSTANCED_PROP`).
- 2단 GI 베이크: 메시 dedup → BLAS 공유, 월드 전개 없음(메모리 ∝ 메시 종류 수). `InstancedRadianceScene`.
- **MeshFilter-free 경로**: `TemplateInstanceSource`(Mesh 템플릿[] + per-template Matrix4x4[][]) → 로컬 Tri[][]·`Instance{MeshIndex,L2W}`·메시 알베도·인스턴스 대표점·시드. 코어 무수정 재사용. 대표점은 `AnchorMode`(`Center`/`LocalTopLift`/`WorldUpLift`/`SurfaceNormalOffset`)로 배치해 솔리드 내부 자기차폐 회피.
- **정적 대량(DrawMeshInstancedIndirect) 하이브리드**:
  - 대형 메시(건물 5~10종) → **텍스처 라이트맵**(AtlasApplyDebug).
  - 소형 메시(프롭, ~수만) → **per-instance SH9 2-프로브(상/하)**, 보간 축 = 인스턴스 로컬 up(임의 회전 정합). `StructuredBuffer<float4>` 인스턴스당 14개(iid*14).
  - 차폐 씬(2단 BVH)엔 크기 무관 전부 포함 → 서로 그림자/바운스 반영.
  - 직사광은 SH 밖(셰이더 실시간). SH엔 간접+환경만.
- **Occluder/Receiver 분리**(v14.11): 차폐에만 참여하고 굽지 않는 메시(`AtlasApplyDebug.occluders`) — 프롭·건물은 그림자만 드리우고 자신은 굽지 않음(지형 QuadTree 는 2026-08-18 로드맵 제외).
- xatlas류 "메시별 고유 uv2"는 인스턴싱과 충돌 → 미도입.
