### 어셈블리 참조 그래프

```
Runtime  ── Unity.Burst / Unity.Collections / Unity.Mathematics
   ▲
   ├── Tests   ── Runtime + Burst/Collections/Mathematics
   ▲       ▲
   ├── Editor  ── Runtime, Tests   [includePlatforms: Editor]
   └── Samples ── Runtime, Tests
```

네임스페이스: `HuskyLibs.CustomLightmapper` (베이크 코어는 `.Bake`, 에디터 툴은 `.EditorTools`).
전 어셈블리 `allowUnsafeCode: true`, `rootNamespace: HuskyLibs.CustomLightmapper`.

> ⚠ CHANGELOG는 "Tests / Samples 는 Editor 플랫폼 전용 → 소비자 빌드 제외"라고 기재하지만,
> 실제 `Tests`·`Samples` asmdef의 `includePlatforms`는 **빈 배열**(전 플랫폼)이다.
> `Editor` asmdef만 `["Editor"]`로 제한돼 있다. 소비자 빌드에서 Tests/Samples를 제외하려면
> 두 asmdef에 `includePlatforms: ["Editor"]`를 추가해야 한다.

### 7.2 기능 차이

| 항목 | 문서 기재 | 실제 |

| **RGBAHalf HDR 출력** | ✅ 전달 (`hdrOutput` 토글) | **미구현** — `hdrOutput`/`RGBAHalf`/`IsHdrMode` 심볼 없음. 아틀라스는 RGBA32 + `linear:true` |
| 디버그 인코딩 | RGBA32 + **감마**(`ToColor`) | 감마 인코딩 **없음** — linear 텍스처에 클램프만 |
