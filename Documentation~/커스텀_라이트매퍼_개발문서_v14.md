# 커스텀 라이트매퍼 개발문서 (v14)

> 구현 상세. 기획서 v14와 짝. 네임스페이스 `HuskyLibs.CustomLightmapper`(베이크 코어 `.Bake`, 에디터 `.EditorTools`).
> **v14: 인스턴싱 SH 트랙 SH-1~SH-5 엔드투엔드 완결 + 검증 자동화.** 어댑터 `TemplateInstanceSource`(`AnchorMode` 4종 프로브 배치, 타입 네임스페이스 승격). SH-1 `SH9`, SH-2 `BurstSHBaker`(1바운스+앰비언트), SH-3 `SHInstanceBuffer`/`SHPacked`(7×float4), SH-4 `SHDebugView`/`SHBakeDemo`, SH-5 `EvaluateSH9.hlsl` + `InstancedSH_URP`(2-프로브 수직음영) — 실 드로우(`SHRenderDemo` `DrawMeshInstancedIndirect`)·아티팩트 4종 수정(v13.3)·**GPU 디코드 자동 검증 `SHEvalProbeGpuTests`**(v14)까지 완료. 실 템플릿 FBX(Adonis_Snackbar) 반입·**전환 검증 완료**(v14.1: 멀티 submesh 드로우 + 양면 렌더).
> 검증: SH-1 `SH9BakeTextureTest`, SH-2 `BurstSHBakerTests`, SH-3 `SHPackedTests`, SH-5 `SHEvalProbeGpuTests`(실 StructuredBuffer 왕복 GPU≡CPU), 어댑터 `TemplateInstanceSourceTests` — 전부 `LightmapEvaluateDebugger.RunAll`에 배선. 기반 G0~G3(Burst)은 CPU와 ε 동등(77만 텍셀 mean≈0). 잔여: 다바운스·인스턴스 오프셋 인덱싱 검증 (임의 회전 프로브 축은 v14.2 완료, BIRP 포팅은 **보류** — SH 트랙은 URP 확정, 2026-07-09 결정). 상세는 §8·§11.1b·§12.

## 1. 파이프라인 ↔ 모듈 (현재 유효)

```
Half-Edge → 차트분할 → 평면투영 → 밀도정규화 → 패킹 → uv2/SeamTable 통합
                                                              │
   per-instance ST  ←  텍셀 복원  ← ─────────────────────────┘
   LightmapAllocator    TexelMapper
        │
        └─→ 씬 RadianceScene 구성 → 텍셀별 EvaluateRadiance → 공유 아틀라스 → LightmapDebug 셰이더
            [C1 BVH + C2 라이팅(AO/Direct/Indirect) 구현·검증 완료 · Burst G0~G3 백엔드 병행(§11)]
```

## 2. A1 — 메시 구조 & 차트 분할
- **HEMesh/HalfEdge (WeldedHalfEdge)** — Half-Edge(DCEL), `NativeArray`+`float3`, weld 내장(MeshCleaner 스탠드인).
- **ChartSegmenter** — best-first 영역성장(MinHeap), 이면각 시임컷, 결정적 시드.
- **ChartMesh** — 차트-로컬 메시 + 경계 루프.
- **(편집)** `ChartSegmentationDebugger`, `HalfEdgeConversion`.

> 참고: 등록 스냅샷(/mnt/project)엔 UV 조립·C1·C2·베이크 파일이 포함되며, A1/A2 일부 leaf 소스(HEMesh/HalfEdge/ChartSegmenter/ChartMesh)는 미포함이라 본 문서에서 재검증 대상이 아니다(엔트리 `ParameterizationPipeline`는 포함·동작).

## 3. A2 — 평면투영 & 검증
- **PlanarProjector** — 평균 노멀 평면 직교 투영.
- **UVValidator** — 부호면적 foldover 검출.
- **(편집)** `ParameterizationTestDebugger`.
- xatlas 미도입(자체 경로).

## 4. A3/A4 — 정규화·패킹·통합 / 텍셀·ST
- **ChartFlattener** — Planar→LSCM→MVC 디스패처(foldover 재검사).
- **LSCMSolver / MVCFallback** — **스텁**(`LogWarning("미구현 stub")`, no-op).
- **UVPacker** — `DensityNormalizer`(s=√(meshArea/uvArea)) + `ShelfPacker`.
- **UVAssembler** — `SeamTable`, `Assemble`(uv2=ch1), `ParameterizationPipeline.Run`→`ParamResult`.
- **TexelMapper** — uv2→`LumelMap{WorldPos,WorldNormal,Valid,Bounds}`.
- **LightmapAllocator** — `InstanceLM{Id,LightmapIndex,ScaleOffset}`, `Allocate`(변∝√worldArea·density).
- **AtlasApplyDebug + LightmapDebug.shader** — per-instance ST 적용. (§5.5 라이팅 모드 추가됨)

### 5.5 후처리 (step 8) — 구성 완비(구현·전달)

| 파일 | 구현 상태 |
|------|----------|
| `LightmapPostProcess.cs` | ✅ `Dilate`(거터 Push-Pull). **Burst `IJobParallelFor`** — 더블버퍼 핑퐁(패스 시작 valid만 소스 → 패스 내 충돌 없음), 핸들 체이닝. 관리형 `Dilate(Color[],…)` 래퍼 + `DilateBurst(NativeArray<float4>,…)` 직결 진입점 |
| `LightmapSeamStitch.cs` | ✅ Tier1(정점) `Stitch` + **Tier2(모서리) `StitchEdges`**(공유 t DDA 순회·Jacobi 누적) + `Seg`/`UvToTexelIndex`/`UvToTexelCoord` |
| `SeamEdgeBuilder.cs` | ✅ Tier2(Route A). uv2 토폴로지+그룹 → 경계 시임 모서리 쌍 유도(끝점 GA/GB 정규화, 미러 대응) |
| `SeamGate.cs` | ✅ 노멀 게이팅. `NormalsWithin`(Tier1)·`EdgeGroupSmooth`(Tier2) — 양쪽 노멀 각이 `seamMaxAngleDeg`(기본 45°) 이내일 때만 스티칭(하드 엣지 보존) |
| `LightmapPostProcessPrev.cs` | ✅ `_prev` 직렬 관리형 dilation(비교/회귀용 보존) |

- **순서**: blit → 시임 스티칭(Tier1) → dilation → SetPixels. (스티칭=경계 valid 정렬, dilation=거터 전파)
- **AtlasApplyDebug 통합**: 패치 형태(전달) — `validMask` 추가, `Assemble`의 SeamTable 캡처(기존엔 `_`로 폐기), per-page 그룹 수집, 후처리 호출. 등록본 덮어쓰기 금지(OccluderKind/RadianceDiffTest 보존).
- **Tier2(모서리) 구현**: `SeamEdgeBuilder.Build` → 시임 모서리 쌍 → `StitchEdges`(공유 t DDA, Jacobi 누적으로 길이불일치·다중 시임 교차 텍셀 순서무관 수렴). 끝점도 Jacobi로 N-way 수렴(Tier1 정점은 보조).
- **RGBAHalf 출력**: 라디언스 모드 아틀라스 RGBA32 → **RGBAHalf 선형 HDR(무클램프)**, `linear:true`. `hdrOutput` 토글. BlitRegion 라디언스 분기(`IsHdrMode ? 선형 : ToColor`).
- **인코딩 해소**: RGBAHalf=선형 저장이라 스티칭·dilation 평균이 **선형에서 정확**(기존 감마 근사 caveat 제거).
- **셰이더**: `LightmapDebug.shader`는 RGBAHalf 선형 샘플→출력(수동 감마 제거 확인). 등록 스냅샷에 .shader 미포함이라 패치 별도.
- **노멀 게이팅**: 큐브 모서리처럼 노멀이 꺾인 시임은 실제 음영 불연속 → 평균 제외. uv2 노멀(오브젝트) 비교, 비균등 스케일 정밀화는 월드 노멀 전달로 가능. `seamMaxAngleDeg` 인스펙터.
- Burst: dilation은 IJobParallelFor 완료. StitchEdges는 그룹 평탄화로 Job화 가능(차기).

## 11. GPU/Burst 로드맵 (계획 · 결정 ⑩ 실행)

핵심 병목 = **텍셀별 경로추적**(수백만 텍셀 × spp × 바운스 × BVH 순회). UV·패킹은 일회성 → 대상 아님.
순서: **Burst(저위험·NativeArray 재사용) → GPU(대규모)**. 각 단계는 기존 CPU를 ground truth로 ε-교차검증.

### 11.0 설계 원칙
- **POD 평탄화**: Burst/GPU는 `IOccluder`/`ISky`/`IRadianceScene` 가상 디스패치 불가 → 씬을 blittable NativeArray(SoA)로. BLAS/TLAS 노드·tri(+submesh/albedo idx)·인스턴스(L2W·노멀행렬·blasOffset)·알베도 테이블·광원(enum+params). 기존 `BVH`(NativeArray 평탄)·`SceneRadianceBuilder` 재사용.
- **인터페이스는 ground truth 보존**: CPU 경로(IOccluder 등) 정답 기준 유지, Burst/GPU는 별도 POD 경로. 백엔드 enum(CPU/Burst/GPU) 선택.
- **결정성·교차검증**: 텍셀 시드(`seed + li*해시`) 유지. 부동소수 차이 → **ε 허용오차**(fast-math off). 단 **RayAABB/RayTri/Rng/CosineHemisphere 를 재사용**하면 비트동일이 가능 → G0·G1 은 사실상 정확일치로 검증됨.
- **접근자 패치**: 평탄 데이터 노출용 가산 패치 — `BVH.{NodesRO,TriIdxRO,TrisRO}`, `TwoLevelBVH.{TlasRO,InstIdxRO,InstanceWorldToLocal,InstanceNormalMatrix,InstanceMesh,Blas}`. 로직 무변경.

### 11.1b 구현 상태 (전달)
- **G0a** `BurstBVH.cs` — 단일레벨 static 순회. `BVH.RayAABB`·`RayGeometry.RayTri` 재사용 → 비트동일. (전용 `BurstBVHTests` 미분리 — `BurstSceneTests` 로 통합 검증.)

- **G2** `BurstDirect.cs` — `DirectJob : IJobParallelFor` + `Compute`. `EvaluateDirect` 동일 식(L·ndl·그림자·백페이스).
- **G3** `BurstIndirect.cs` — `IndirectJob`(반복형 바운스+RR+NEE+하늘×π, per-texel 시드 `Seeds[]`) + `BurstSky`(ISky POD 미러) + `BurstRadianceBaker`(Direct+Indirect 합성, CPU/Burst 분리). `ClosestHit`(모드 A: 위치·역전치 월드노멀·메시 알베도)는 `BurstScene.meshAlbedo` 사용.

- 테스트: `BurstSceneTests`(G0) + `BurstRadianceCompareTests`(G2/G3 ≡ RadianceCore). 디버거 메뉴 "Run All Tests"/"Run Burst Radiance Compare".
- **버그 수정(전달)**: ① `BurstScene.meshAlbedo` Dispose 누락 누수 ② `IntersectBlas` `hT` 초기화 누락(=0 → closest-hit 항상 실패; G0 IntersectInstanced·G3 ClosestHit 동시 차단) ③ `BurstScene` NativeArray `[ReadOnly]` 누락(IJobParallelFor 병렬 순회 IndexOutOfRange).

### 11.2 권장 분기
**G0–G3(Burst) 먼저 완주** — 저위험·새 셰이더 언어 불필요·큰 속도향상, 그리고 **같은 알고리즘을 Burst에서 정답으로 확정 → G5 compute가 그걸 미러**(GPU 포팅 사전검증). 이후 **G4–G6(GPU)** 로 프로덕션 규모.
교차검증 하니스(단계별 1): `BurstOccluderCompare`(≡BVH) / `BurstRadianceCompare`(≡RadianceCore, Cornell·energy) / `GpuRadianceCompare`(≡CPU) — 전부 기존 ground truth 재사용.

### 11.3 주의
- 인터페이스→POD 전환이 G0 핵심 작업량. Built-In RP 무관(compute는 RP-agnostic).
- 이 레이 엔진은 **Track B(프로브)도 공용** → 두 트랙 공통 자산.
- fast-math/GPU 부동소수 발산 → ε 비교, 검증 시 fast-math off.

## 13. 모듈 독립화(asmdef) · 버전 호환

### 13.1 Assembly Definition
현재 프로젝트는 Unity 6(6000.4)이며 모든 스크립트가 `Assembly-CSharp` 로 컴파일된다. CustomLightmapper 를 독립 어셈블리로 분리:
- 네임스페이스 `HuskyLibs.CustomLightmapper.*` 의 **외부 의존 없음**(폴더 밖 코드가 이 모듈 타입을 참조하지 않음) → asmdef 분리 시 외부 참조 깨짐 없음.
- **런타임** `Script/HuskyLibs.CustomLightmapper.asmdef` — refs: `Unity.Burst`, `Unity.Collections`, `Unity.Mathematics`. (`NativeArray`/`IJobParallelFor` 는 엔진 코어라 무참조; `[BurstCompile]`·`float3` 때문에 Burst·Mathematics 필수.)
- **에디터** `Script/Test/Editor/HuskyLibs.CustomLightmapper.Editor.asmdef` — `using UnityEditor` 쓰는 3개 스크립트(LightmapPostProcessCompareMenu/LightmapAllocatorDebugTool/UVLayoutViewer) 수용. `includePlatforms:["Editor"]`, 런타임 asmdef 참조.
- `TexelMapperDebug` 의 `UnityEditor.AssetDatabase` 는 `#if UNITY_EDITOR` 가드라 런타임 asmdef 에서 무해(에디터 컴파일 시 자동 UnityEditor 참조, 빌드 시 스트립).
- 전제: 미사용 using 제거로 Entities/UniTask/NativeTrees 의존 제거 완료. **에디터 재컴파일로 참조 누락 검증 필요**(컴파일 불가 환경에서 작성).

### 13.2 Unity 2021.3 동작
- **언어/패키지**: C# 9(`using var`·readonly member·`Span<T> stackalloc`) 모두 2021.3 지원. Burst/Collections/Mathematics 2021.3 호환 버전 존재.
- **수정한 비호환 API**: `GameObject.FindObjectsByType<Light>()`(2022.2+ 전용) → `FindObjectsOfType<Light>()`(2021.3~Unity6 공통, U6 에선 deprecated 경고만). 1곳(AtlasApplyDebug).
- **남은 확인 항목**: 코드 자체엔 2022+ 전용 API 없음(전수 grep: `FindObjectsByType`/`Awaitable`/`AsyncGPUReadback`/`Reinterpret` 미사용). 단 manifest 의 `com.unity.entities 6.4.0` 등 일부 패키지는 Unity 6 전용 버전이므로, 2021.3 빌드 시 **패키지 버전 다운그레이드(매니페스트)**가 별도로 필요(코드 무관, 모듈은 Entities 비의존).
