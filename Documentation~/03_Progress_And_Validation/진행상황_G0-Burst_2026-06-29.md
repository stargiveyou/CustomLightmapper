## 1. 한 줄 요약
**G0 Burst 경로 토대 구축** — 관리형 `BVH`/`TwoLevelBVH` 순회를 가상 디스패치·관리 타입 없는 **POD 구조체(`BurstScene`) + static 순회 함수(`BurstBVH`/`BurstTwoLevelBVH`)** 로 추출했다. 동일 노드 레이아웃 + 동일 `RayGeometry.RayTri` 를 재사용하므로 관리형과 **'비트 동일'** 이 계약. 이번 작업에서 `BurstTwoLevelBVH` 컴파일·로직 버그 3건을 수정하고, 관리형을 ground truth로 한 **교차검증 테스트(`BurstSceneTests`)** 를 추가했다. 실제 `[BurstCompile]` Job 래핑은 **G1 AO부터** 적용 예정(현재는 정확성·교차검증 우선).

## 2. G0 구성 (`Script/LightmapEvaluate/`)

| 파일 | 역할 | 상태 |
|---|---|---|
| `Occluders/BurstBVH.cs` | 단일레벨 BVH 순회 static 함수. `NativeArray<>.ReadOnly`(Node/triIdx/Tri)로 동작. `Intersect`/`Occluded`. | ✅ 구현 |
| `BurstScene.cs` | 2단 BVH 전체를 평탄 `NativeArray` 로 펼친 POD 빌더(`Create`)+`IDisposable`. TLAS·인스턴스(world→local/normal matrix/BLAS)·BLAS(노드/triIdx/tris + 메시당 START/COUNT 오프셋). | ✅ 구현 |
| `Occluders/BurstTwoLevelBVH.cs` | 2단 순회 static 함수. `IntersectInstanced`/`Occluded`/`TransformNormalToWorld`. 관리형 `TwoLevelBVH` 와 동일 로직, 오프셋만 적용. | ✅ 구현 (버그 3건 수정) |
| `BurstAO.cs` | G1 AO Job 진입점. **현재 빈 스텁(`class BurstAO {}`)** — 미착수. | ⬜ 스텁 |

### 설계 의도(코드 주석 계약)
- 노드를 `NativeArray` 평탄 배열로 보관 → 추후 Burst Job + GPU `StructuredBuffer` 가 **동일 레이아웃** 을 그대로 사용.
- 순회는 **명시적 스택(재귀 X, `stackalloc int[64]`)** → Burst/관리 공용.
- 프리미티브 교차는 `RayGeometry.RayTri` **재사용** → 관리형 BVH와 동일 프리미티브 → 교차검증이 '순회/컬링/평탄화'만 검사.
- 레이 방향은 정규화 가정 X → 2단에서 인스턴스 로컬로 변환된(비정규화) 방향도 그대로 사용(파라메트릭 T 일관).

## 3. 이번 작업에서 수정한 버그 (`BurstTwoLevelBVH.cs`)
> 모두 컴파일/순회 정확성에 직결 — 수정 없이는 어셈블리 빌드 불가 또는 잘못된 삼각형 참조.

1. **잘못된 `using` 오삽입** — `using Unity.Cecil.Awesome.CFG;` (자동완성 오삽입) 제거.
2. **BLAS 삼각형 오프셋 버그** — `IntersectBlas` 의 `triBase = s.blasTriIdx[mesh]` → **`s.blasTriStart[mesh]`**. `blasTriIdx` 는 삼각형 인덱스 배열인데 메시 인덱스로 잘못 접근 → 엉뚱한 삼각형 참조. `OccludedBlas`(정상)와 동일 기준으로 정정.
3. **구문 에러(쉼표 누락)** — `IntersectInstanced(..., float tmin float tmax)` → `float tmin, float tmax`.

남은 IDE 진단은 모두 Information(스타일: `new` 식 단순화, 네임스페이스/폴더 불일치)으로 **에러 없음**.

## 4. 검증 (`Script/Test/BurstSceneTests.cs`) — 신규
`BurstSceneTests.RunAll()` — **관리형 `TwoLevelBVH` 를 ground truth로 한 교차검증**. 동일 노드 레이아웃·동일 RayTri 이므로 불일치 = 평탄화/오프셋/순회 버그(수치오차 아님 → Eps=1e-4 사실상 0).

| 케이스 | 검사 항목 |
|---|---|
| **IntersectInstanced** (20인스턴스 회전+비균등 스케일, 5000레이) | `Valid` / `T` / `InstanceIndex` / `MeshIndex` / `MeshTriIndex` 전부 일치 |
| **Occluded** (가변 maxDist, 5000레이) | bool 일치 |
| **TransformNormalToWorld** | 적중 인스턴스의 로컬 노멀 → 월드 노멀 일치 |
| **엣지** | 인스턴스0 씬(Occluded false·Intersect 미스), `Create`/`Dispose` 왕복 누수 방지 |

- 씬 분포는 `BVHTests.TwoLevelFuzz` 와 **동일 메시/시드(424242)** → 기존 C1 검증과 회귀 비교 가능.
- 통합: `LightmapEvaluateDebugger` 에 **`Run Burst Scene Tests (G0)`** 버튼 추가 + **`Run All Tests (C1+C2)`** 에 합류.
- ⚠️ **실측 PASS 수치는 Unity 에디터에서 컴파일·실행 후 확정 필요**(이 스냅샷은 코드 기준; 본 환경에서 Unity 런타임 미실행).
