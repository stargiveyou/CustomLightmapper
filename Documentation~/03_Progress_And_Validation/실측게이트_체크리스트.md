# 실측 게이트 체크리스트 — G0~G3 검증 확정

> 목적: 컴파일 불가 환경에서 작성된 Burst G0~G3 코드를 **에디터에서 재컴파일·재검증**해 "전달"→"검증 완료"로 확정.
> 기준: 기획서 v12 §11 「다음 단계」 1번(선행·필수). 통과 후 → G4(GPU) 또는 Track B(식생) 분기.

---

## 0. 사전 준비 (스테일 방지 — 가장 중요)

- [ ] **Burst 컴파일 강제 리프레시** — Jobs ▸ Burst ▸ `Enable Compilation` 켜짐. 옛 캐시 의심 시 `Library/BurstCache` 삭제 후 재컴파일
- [ ] **에디터 재컴파일** — 스크립트 저장 → 컴파일 에러 **0** (에러 있으면 이하 무의미)
- [ ] **asmdef 참조** — `HuskyLibs.CustomLightmapper.asmdef`(Burst/Collections/Mathematics) + `.Editor.asmdef` 정상 로드(참조 누락 경고 없음)
- [ ] **측정 환경** — 헤드리스 테스트는 Edit 모드로 충분. Burst 실측 속도는 **Play 모드/빌드**에서 한 번 더(에디터 Mono 오버헤드 배제)

## 1. G0 — 구조 순회 비트동일

- [ ] **`BurstSceneTests`(G0)** → `BurstTwoLevel` ≡ 관리형 `TwoLevelBVH`
  - [ ] 20인스턴스(회전+비균등 스케일) × 5000레이: Valid/T/InstanceIndex/MeshIndex/MeshTriIndex 전부 일치
  - [ ] ΔT < 1e-4, 노멀 역전치 ΔN 미세, `--- N/N PASS ---`
- [ ] **회귀 관찰점** — `IntersectBlas` `hT` 초기화 버그 재발 없는지: **hits > 0**(closest-hit 실제로 잡힘). hits=0이면 재발 신호

## 2. G2 / G3 — 라이팅 CPU 동등

- [ ] **`BurstRadianceCompareTests`(G2/G3)** → `BurstDirect`/`BurstIndirect` ≡ `RadianceCore`
  - [ ] Direct(NEE+그림자) maxDiff < ε
  - [ ] Indirect(경로추적+RR, 다바운스) maxDiff < ε (per-texel 시드 동일 → 사실상 0)
  - [ ] `--- N/N PASS ---`
- [ ] **비자명성** — 결과 전부 0 아님(nonZero > 0). 0만 나오면 씬/알베도/시드 연결 오류

## 2.5 P1 — Mesh+Matrix 어댑터 등가성 (신규)

> `TemplateInstanceSource`(MeshFilter 없는 Mesh+Matrix 어댑터) ≡ MeshFilter 경로(BuildGiScene). `Run All Tests (C1+C2)` 에 편입됨.

- [ ] **`TemplateInstanceSourceTests`** → 어댑터 씬 ≡ 레퍼런스(직접 조립)
  - [ ] ① 구조: `instances`(개수·MeshIndex·L2W) / `uniqueMeshes` Tri round-trip / `instanceTemplate ≡ MeshIndex`
  - [ ] ② 대표점: `instancePoints[k] ≡ M·bounds.center`
  - [ ] ③ 거동: 5000레이 `IntersectInstanced`(Valid/T/inst/mesh/tri) + `Occluded` ≡ 레퍼런스 BVH (hits > 0)
  - [ ] ④ 알베도: `templateAlbedo=null` → 0.5 회색 폴백
  - [ ] `--- N/N PASS ---`
- [ ] **asmdef 경고 해소** — 재컴파일 후 `TemplateInstanceSourceTests` 타입 충돌 경고(Assembly-CSharp ↔ asmdef 이중컴파일) 사라짐 확인. 남으면 .csproj 스테일 → 재임포트

## 3. 베이크 백엔드 실측 (핵심 게이트)

- [ ] **AtlasApplyDebug**: `mode = RadianceGI`, `radianceBackend{CPU,Burst}` 토글 노출 확인
- [ ] **ContextMenu "RadianceGI Backend Diff (CPU vs Burst)"** 실행
  - [ ] 실측 재현: **77만 텍셀 mean≈0, over(1/255)=1** (또는 그에 준하는 MATCH)
  - [ ] mean 크거나 over 많으면 → 시드 규약(`seed + li*2654435761u`)/알베도/씬 연결 불일치 의심
- [ ] **CPU 백엔드 1회 베이크** → 결과 아틀라스 확인
- [ ] **Burst 백엔드 1회 베이크** → CPU와 육안·수치상 동일
- [ ] **속도 로그** — Burst가 CPU 대비 유의미하게 빠름(Play/빌드에서 이득 큼)

## 4. 후처리 파이프라인 (step 8)

> 실존·실행 가능한 테스트만. `LightmapPostProcessTests`·`SeamGateTests`·`NormalTransformTests` 는 **트리에 소스 없음(미작성)** → 게이트에서 제외(작성 시 재편입).

- [ ] **`LightmapPostProcessCompare`** → Burst dilation ≡ 직렬(_prev) + 속도
- [ ] **`LightmapSeamStitchTests`**(Tier1) / **`SeamEdgeTests`**(Tier2) → 평균·정규화·미러·길이불일치 무누락
- [ ] **노멀 게이팅(육안)** — `seamMaxAngleDeg`(`AtlasApplyDebug` 필드) 적용: 큐브 모서리(90°) 스티칭 제외로 하드 엣지 보존, 매끈 곡면 통과. (전용 `SeamGateTests` 미작성 → 아틀라스 육안 확인으로 대체)
- [ ] **처리 순서** — `AtlasApplyDebug` 실제 호출 순서로 확정(시임 스티칭 → Dilate → SetPixels)
- [ ] **RGBAHalf** — `hdrOutput` ON에서 아틀라스 포맷 = RGBAHalf(RGBA32 아님), 밝은 직사광 1.0 클램프 안 됨

## 5. 셰이더 적용

> **파이프라인 결정: 개발은 URP로 진행, BIRP 전환은 추후.** `LightmapDebug.shader`(URP 전용)는 개발 파이프라인과 일치 → 블로커 아님. BIRP 변형 셰이더는 최종 전환 시점의 별도 과제.

- [ ] **URP 렌더 정상** — `LightmapDebug.shader` 화면 정상 렌더(마젠타 아님)
- [ ] **감마 이중보정 없음** — 셰이더가 RGBAHalf 선형을 그대로 샘플(수동 `pow` 없음)
- [ ] **(추후)** BIRP 전환 시 BIRP 변형 셰이더 작성 — 지금 게이트 대상 아님

## 6. 게이트 통과 판정

아래 **모두 충족** 시 G0~G3 "검증 완료" 확정 → 다음(G4 / Track B) 진행:

- [ ] 1·2·2.5·3·4 테스트 전부 `PASS` + Backend Diff MATCH
- [ ] G0 hits > 0, G2/G3 nonZero > 0 (비자명)
- [ ] 컴파일 에러 0, asmdef 참조 정상
- [ ] 셰이더 URP 정상 렌더 확인(BIRP 전환은 추후·게이트 대상 아님)
