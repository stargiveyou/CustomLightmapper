> 목적: Unity·GPU 없는 환경에서 작성·헤드리스 검증만 거친 v15.12~v15.18 작업(C0 씬 수집 · B1-6 알파 잎 · A3 LSCM/MVC ·

## 3. 실씬 수동 확인

### 3.1 회귀 — 로컬 광원 없는 기존 씬
- [ ] 재베이크 결과가 이전(저장된 결과 에셋)과 같아 보임. 씬에 Point/Spot/Area 라이트가 있으면 기본 `localLightSource = Scene` 이라 달라지는 게 정상 → `None` 으로 비교

### 3.2 진행형 미리보기 (`AtlasApplyDebug` 우클릭 "Bake Progressive (Preview)", RadianceGI)
- [ ] 저 spp 결과가 바로 보이고 패스마다 매끈해짐 · 에디터 응답 유지 · `progressiveStatus` 갱신
- [ ] "Cancel Progressive Bake" → 그 시점 결과로 확정(SSAA·저장 생략)
- [ ] 진행 중 Bake & Apply · Restore Originals · 컴포넌트 비활성 · 스크립트 재컴파일 → 에러·NativeArray 누수 경고 없음
- [ ] 끝까지 돌린 결과 = 같은 설정의 Bake & Apply

### 3.3 적응 샘플링 · GPU 후처리 · 배치 (성능 실측)
- [ ] `adaptiveSampling` on, `indirectSamples` 128~256 → 완료 로그 `adaptive(spp 평균 X/N, 경로 Y%)` 와 노이즈 비교, `adaptiveThreshold` 0.02~0.05 조절
- [ ] `gpuPostProcess` on/off → 시임·거터 모양 동일, 로그 `stitch(…,GPU)`·`dilate=N×(GPU)`, `post=` 시간
- [ ] `bakeBatchLumels` 0 ↔ 기본(1<<20) → 결과 동일, `bake=` 시간 비교 (소형 인스턴스가 많을수록 이득 기대)

### 3.4 로컬 광원 — 텍스처 라이트맵 (L1)
- [ ] Point / Spot / Area(Rect) / Disc 각각 배치 → URP 실시간 라이트(같은 라이트 Realtime)와 밝기·감쇠·스포트 가장자리 비슷
- [ ] **Area 라이트 방출 방향**(transform forward) 이 Unity 와 같은 쪽 — 반대면 수정 필요
- [ ] 천장에 붙인 면광원도 빛이 나옴(그림자 레이가 천장에 막히지 않음)
- [ ] Baked Shadow Radius → 반그림자 · Shadow Type None → 그림자 없음
- [ ] 면광원 밝기 감 — 규약은 방출 휘도 = color × intensity. Unity 내장 라이트매퍼와 차이가 크면 스케일 조정 검토
- [ ] `localLightsFollowBakeType` on → Mixed = 간접만, Realtime = 제외 · 로그 `lights=P.. S.. R.. D..(출처)`
- [ ] CPU / Burst / GPU 백엔드 결과가 같은 모습

### 3.5 로컬 광원 — SH·프로브 (L2)
- [ ] `ProbeVolumeBaker` + 램프 → 램프 근처 식생이 밝아지고 방향성 맞음 · 에셋 `lightLog`
- [ ] `InstanceSceneBaker` + 램프 → 인스턴스 밝기 변화 · 에셋 `lightLog`
- [ ] GPU ↔ Burst 백엔드 결과 동일한 모습
- [ ] 알려진 한계 확인: 강한 점광원 바로 옆 프로브는 SH L2 대역 한계로 방향성이 뭉개짐(텍셀 라이트맵 쪽이 정확)

### 3.6 이전 단계
- [ ] **C0**: "Collect Scene (C0)" 리포트(후보 수 = 활성 MeshFilter 수) · "Verify Determinism (C0-V1)" · Undo 복원
- [ ] **B1-6**: 잎 카드(컷아웃 머티리얼) 아래 프로브가 밝아짐 · `alphaLog`
